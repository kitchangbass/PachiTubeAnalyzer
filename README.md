# 🎰 PachiTubeAnalyzer

## 概要

PachiTubeAnalyzer は、パチンコ・パチスロ関連YouTube動画を分析するためのツールです。

YouTube Data API と Gemini AI を利用し、

- 動画分析
- コメント分析
- AI要約
- 改善提案
- ランキング
- ダッシュボード

を自動生成します。

---

## 主な機能

- YouTube動画検索
- 動画情報取得
- コメント取得
- チャンネル分析
- AIによる要約
- コメント感情分析
- 良い点・改善点分析
- 日別・月別ランキング
- Looker Studio連携

---

## 使用技術

- Google Apps Script
- Google Sheets
- YouTube Data API v3
- Gemini API
- Looker Studio
- GitHub
